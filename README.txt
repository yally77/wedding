정근과 예나의 픽셀 결혼식 방명록

Node.js 20 이상에서 npm start로 실행합니다. 외부 호스팅에서는 HOST=0.0.0.0을 설정하세요.
관리자 비밀번호는 저장소 코드 대신 ADMIN_PASSWORD 실행 환경변수로 설정합니다.
이 배포본은 비밀번호가 없으면 관리자 로그인을 비활성화합니다.
방명록은 guestbook-data.json에 저장되며 Git에 포함되지 않습니다. 이 파일을 영구 보존해야 합니다.

GitHub Pages는 정적 파일 호스팅이므로 이 저장 서버를 실행할 수 없습니다.
Codespaces 포트 공유는 Codespace가 실행 중일 때만 사용할 수 있습니다.
상시 공유할 주소에는 Node.js 서버와 영구 디스크가 있는 호스팅이 필요합니다.

아직 GitHub 업로드나 공개 배포는 완료되지 않았습니다.
